# YouTube ライブコメント音声読み上げクローム拡張機能

YouTube のライブチャットを、音声合成ソフト「VOICEVOX」のずんだもんなどの声で読み上げる Chrome 拡張機能です。

🛒 **[Chrome ウェブストアでインストール](https://chromewebstore.google.com/detail/gdakacmdogbakjhalfjkclkagdojhooi?hl=ja)** ｜ 🌐 **[紹介ページ（LP）](https://kat-log.github.io/youtube-voicevox-standalone/)**

## 📋 概要

YouTube のライブ配信に流れるコメントを自動で取得し、音声で読み上げます。画面を見ながら別の作業をしていても、コメントを聞き逃さずに楽しめます。

**APIキーは不要です。** 拡張機能を入れて、PC にローカル版 VOICEVOX を入れて起動するだけで、ライブ配信でもアーカイブでもそのまま使えます。

- **コメントの取得**は、YouTube のチャット欄を直接読み取る **DOM モード**（既定・APIキー不要）
- **音声の生成**は、PC にインストールした **ローカル VOICEVOX**（既定・推奨・回数制限なし）

YouTube Data API v3 の公式 API モードや、WEB 版 VOICEVOX API も引き続き選べます（[後述](#-apiキーについて任意)）が、どちらも必須ではありません。

## 🚀 3 ステップで使い始める

### 1. 拡張機能をインストール

[Chrome ウェブストア](https://chromewebstore.google.com/detail/gdakacmdogbakjhalfjkclkagdojhooi?hl=ja) からインストールします。
（ソースからビルドして使う場合は[開発者向け](#-開発者向け)を参照）

### 2. ローカル VOICEVOX を入れて起動

1. [VOICEVOX 公式サイト](https://voicevox.hiroshiba.jp/) からアプリをダウンロード・インストール
2. VOICEVOX アプリを起動する（音声エンジンがバックグラウンドで自動的に起動します）
3. 拡張機能のポップアップで「読み上げエンジン」が **ローカル VOICEVOX**（既定）になっていることを確認
4. 「接続テスト」ボタンで接続を確認し、好きな話者を選ぶ

> 接続先は既定で `http://localhost:50021` です。VOICEVOX のポートを変えている場合のみ、ポップアップの入力欄で変更してください。
> 読み上げ中は VOICEVOX アプリを起動したままにしてください。

VOICEVOX を入れずに試したい場合は、読み上げエンジンで **ブラウザ内蔵音声** を選べば設定なしで動きます。

### 3. YouTube を開いて読み上げ開始

1. YouTube のライブ配信ページ（またはアーカイブ）を開き、チャット欄を表示しておく
2. 拡張機能アイコンをクリックしてポップアップを開く
3. 「読み上げ開始」をクリック 🎉

`Alt+Shift+S` で開始、`Alt+Shift+Q` で停止もできます（Mac: `⌥⇧S` / `⌥⇧Q`）。

## 🎙 読み上げエンジン

ポップアップのプルダウンで切り替えられます。

| エンジン | APIキー | 特徴 |
|---|---|---|
| **ローカル VOICEVOX**（既定・推奨） | 不要 | PC の VOICEVOX に直接接続。回数制限なし・高速。同時リクエスト数を 1〜5 で調整可能。接続テストと話者一覧の自動取得つき |
| **WEB 版 VOICEVOX API** | 任意 | インストール不要。APIキーなしでも動作し、キーを設定すると生成が高速化。レート制限あり |
| **ブラウザ内蔵音声** | 不要 | OS / ブラウザ標準の TTS を利用。設定不要ですぐ使えるが、並列再生は非対応 |

## 💬 コメントの取得方式

| 方式 | APIキー | 対応範囲 | スパチャ・メンバーシップ |
|---|---|---|---|
| **DOM モード**（既定） | 不要 | ライブ開始前の待機中・ライブ配信中・**アーカイブ動画**すべて | 読み上げる |
| **公式 API モード**（YouTube Data API v3） | 必要 | ライブ配信中のみ | 読み上げない |

DOM モードは YouTube のチャット表示をそのまま読み取るため、アーカイブのタイムライン同期も正確です。YouTube 側でチャット欄を表示した状態でご使用ください。

DOM モードでは、通常コメントに加えて**スーパーチャット**と**メンバーシップ（メンバー継続メッセージ）のコメント本文**も読み上げます。読み上げるのは視聴者が書いた本文だけで、金額表示・「メンバーになりました」といった定型のアナウンス文は読み上げません。本文のないスパチャ・スーパーステッカー・メンバーギフトの通知も読み上げ対象外です。

## ✨ 主な機能

### 話者

- **話者選択**: ずんだもん、四国めたん、春日部つむぎなど多数のキャラクターから選択
- **ランダム話者モード**: コメントごとにランダムで話者が切り替わる。使う話者は専用ページで選択・検索可能
- **持ち回り制話者モード**: 2〜10 人の話者を順番に割り当て。各スロットに「ランダム」も指定可能
- **お気に入りプリセット**: よく使う話者の組み合わせを保存してワンクリック切り替え
- **テスト再生**: ポップアップで任意のテキストを試聴。全話者を一覧試聴できる専用ページも用意

※ ランダム話者モードと持ち回り制話者モードは排他（どちらか一方のみ有効）

### 音声・再生

- **再生速度**: 0.1 倍速〜3.0 倍速
- **音量**: スライダーで調整（細かさを 10 段階／20 段階／100 段階から選択可能）
- **並列同時再生**: 常時並列（同時再生数 2〜10）、または待機コメント数がしきい値を超えたときだけ発動する切り替えに対応
- **ラッシュモード（自動倍速）**: コメントが溜まると自動で速度アップ、減ったら元に戻る。開始しきい値・倍速時の速度・復帰しきい値を調整可能
- **ランダム再生速度モード**: コメントごとに再生速度を抽選（下限・上限を指定）。ラッシュモード発動中はそちらが優先

### コメントフィルター

- **最新 N 件取得モード**（1〜10 件）
- **文字数フィルター**（最小・最大をデュアルスライダーで指定）
- **絵文字のみのコメントをスキップ** / **絵文字除去**
- **NG ワードリスト**（カンマ区切り・全角半角同一視、該当ワードのみ除去 or コメントごとスキップ）
- **キュー自動キャッチアップ**: 待機コメント数がしきい値を超えたら古いコメントを破棄して最新に追いつく

### 表示・管理

- **コメント処理タイムライン**: 各コメントの待ち→生成→読み上げをリアルタイムに可視化。話者カラム、時間軸ズーム、秒／ミリ秒表示切り替え、列幅ドラッグに対応
- **実績・ランクシステム**: 読み上げ件数に応じて 10 段階のランクアップ 🏆
- **ログ表示**: レベル別（debug/info/warn/error）表示。ポップアップ内のアコーディオンと専用ページで確認可能
- **ステータス表示**: 接続状態・読み上げ件数・キュー待機数をリアルタイム表示。読み上げ中は拡張機能アイコンに件数バッジ
- **ダークモード** 🌙
- **設定のエクスポート／インポート**（JSON）と「デフォルトに戻す」ボタン
- **設定の即時反映・自動保存**（保存ボタン不要）
- **セクションの折りたたみ・並び替え**: ポップアップの各設定セクションを畳んだり、ドラッグで好きな順に並び替え

## 🔑 APIキーについて（任意）

APIキーは**すべて任意**です。既定の「DOM モード × ローカル VOICEVOX」の組み合わせでは一切必要ありません。

### YouTube Data API v3（公式 API モードを使う場合のみ）

公式 API モードでコメントを取得したい場合に必要です。

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成
2. YouTube Data API v3 を有効化
3. 「認証情報」からAPIキーを作成
4. ポップアップの「YouTube API Key」欄に入力し、コメント取得方式を「公式 API モード」に切り替え

拡張機能内のセットアップガイドからも手順を確認できます。

### VOICEVOX API キー（WEB 版 VOICEVOX API の高速化のみ）

WEB 版 VOICEVOX API はAPIキーなしでも動作します。キーを設定すると生成が高速になります。

- 取得: [su-shiki API](https://voicevox.su-shiki.com/su-shikiapis/)
- ポップアップの「詳細設定（VOICEVOX API）」に入力（残ポイントの確認ボタンつき）

## 🔧 トラブルシューティング

**音声が再生されない（ローカル VOICEVOX）**

- VOICEVOX アプリが起動しているか確認してください（読み上げ中は起動したままにする必要があります）
- ポップアップの「接続テスト」で接続を確認してください
- 接続先が `http://localhost:50021` になっているか、VOICEVOX 側のポート設定と一致しているか確認してください

**コメントが読み上げられない（DOM モード）**

- YouTube 側でチャット欄が表示されているか確認してください（チャットを非表示にしていると取得できません）
- アーカイブの場合、チャットのリプレイが有効な動画か確認してください
- ログページでエラー内容を確認してください

**「YouTube API キーが設定されていません」エラー**

- 公式 API モードを選んでいる場合のみ出ます。APIキーが不要なら、コメント取得方式を **DOM モード** に戻してください
- 公式 API モードを使うなら、APIキーが正しいか、YouTube Data API v3 が有効化されているか確認してください

**「この動画はライブ配信ではありません」エラー**

- 公式 API モードはライブ配信中のみ対応です。アーカイブや配信前は DOM モードを使ってください

**読み上げが追いつかない**

- ラッシュモード（自動倍速）、並列同時再生、キュー自動キャッチアップ、最新 N 件取得モードを有効にすると改善します
- ローカル VOICEVOX 使用時は「同時リクエスト数」を上げると生成が速くなります（PC スペックに応じて調整）

**拡張機能を更新・再読み込みした後の挙動がおかしい**

- YouTube のタブを再読み込みしてください

### ログの確認

ポップアップの「ログ表示」またはログページで、コメント取得状況・音声生成のリクエスト／レスポンス・エラー・リトライ状況を確認できます。

## 🛠 開発者向け

### 技術仕様

- **Manifest Version**: 3
- **対応ブラウザ**: Google Chrome
- **言語**: TypeScript
- **ビルドツール**: Vite
- **テスト**: Vitest
- **スタイル**: SCSS

### セットアップ

```bash
npm install
npm run build     # 型チェック + ビルド（dist/ が生成される）
```

Chrome で `chrome://extensions/` を開き、「デベロッパーモード」を有効化して「パッケージ化されていない拡張機能を読み込む」から `dist` フォルダを選択します。

### コマンド

```bash
npm run dev       # watch モードでビルド（開発時）
npm run build     # 型チェック + ビルド
npm run lint      # ESLint
npm test          # Vitest
npm run format    # Prettier
```

### 新しいページを追加したら

`src/hub/hub.html` は全ページへの目次ページです。ページの追加・パス変更・削除をしたときは、`hub.html` のカードも合わせて更新してください。

### リリース

バージョンの正は `public/manifest.json` の `version` フィールドです（`package.json` の `version` は管理外）。

1. `public/manifest.json` の `version` を更新してコミット
2. `git tag v{version}`
3. `git push origin v{version}`

タグの push で GitHub Actions（`.github/workflows/release.yml`）が走り、ビルド → `dist/` の zip 化 → GitHub Release の作成・添付までが自動実行されます。Chrome ウェブストアへの提出は、その zip を使って手動で行います。
